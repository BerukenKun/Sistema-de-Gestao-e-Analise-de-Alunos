# Sistema-de-Gestao-e-Analise-de-Alunos

Desenvolvimento de um sistema em Excel para cadastro, gerenciamento e análise de alunos, utilizando macros.
O projeto conta com um formulário para cadastro de novos alunos, armazenamento das informações em uma base de dados, cálculo automático de valores faturados por curso e geração de indicadores para análise da quantidade de alunos e do faturamento.
Também foram desenvolvidos dashboards e gráficos dinâmicos para facilitar a visualização dos resultados, permitindo analisar a distribuição de alunos por curso, o faturamento e a participação percentual de cada categoria.
